🩸 AI-Based Blood Cancer Prediction System

An AI-based web application designed to provide preliminary blood cancer risk prediction through a user-friendly interface, along with doctor recommendation and appointment management features.

📌 Project Overview

The Blood Cancer Prediction System aims to make preliminary health risk assessment more accessible through a web-based interface.

The application provides dedicated interfaces for users, doctors, and administrators.

✨ Key Features

- User-friendly web interface.
- Blood cancer risk prediction interface.
- User login and authentication interface.
- Doctor information and recommendation interface.
- Appointment management.
- Admin dashboard.
- Responsive frontend design.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons

⚙️ Installation & Setup

1. Clone the repository:

git clone https://github.com/Satwiktiwari124/Blood-Cancer-Prediction.git

2. Open the project folder:

cd Blood-Cancer-Prediction

3. Open the project in Visual Studio Code.

4. Run the application using the configured local server.

🎯 Project Objective

To develop an accessible web-based platform that combines preliminary AI-based health risk assessment with doctor discovery and appointment management.

⚠️ Disclaimer

This project is developed for educational and demonstration purposes only. Its predictions are not a medical diagnosis and should not replace professional medical advice.
